Support

Write to support@iamjarl.com and I will answer. One person builds this, so please say which Mac and which macOS version you are on, and what you were doing when it went wrong. In the app, Help > Send Feedback opens a mail with both filled in.

Patternaut was shaped in a thread on Polyend Backstage, and I still read it. Ideas and questions are welcome there too, where other Tracker owners can weigh in.

The app keeps a log of what it has been doing. Press Log, then Copy, and paste that into the mail. It usually contains the answer.

Where do exported files go?

Wherever you point the export panel. On an SD card from a Tracker, the right place is the Projects folder, inside User, Demos or Artists. A project written straight into Projects itself does not show up in the machine's browser.

Import cannot see my project

Import wants the project folder, the one holding project.mt. Pointing at the patterns folder inside it works too. File, then Open, is a different thing: that opens Patternaut's own documents, not projects from a card.

My sample will not load

WAV files load, including 24-bit and 32-bit float, and other sample rates are converted for you. Other formats are not read yet. Convert to WAV first.

Can it play my pattern?

No. Patternaut has no audio engine, so the hardware is where you hear it. That is a deliberate limit on what the app tries to be, not an oversight.

Which hardware does it write for?

Polyend Tracker+ and Tracker Mini. The file formats are checked against Polyend's own open-source library and against projects written by the hardware itself.
